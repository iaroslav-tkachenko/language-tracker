# Generated concept studies

- Date: 2026-09-05
- Status: Four basic shape studies generated; awaiting product-owner review
- Tool: Built-in OpenAI image generation
- Use case: `logo-brand`
- Output role: Early raster references only, not production assets

All four prompts requested a single square, opaque, flat, vector-friendly app
icon without text, UI, mockups, trademarks, thin details, 3D, texture, shadow,
or watermark. The files have been copied from the tool-managed generation folder
into this project.

## 1. Progress Mosaic

File: `concept-01-progress-mosaic-v1.png`

```text
Use case: logo-brand
Asset type: early concept render for a mobile PWA app icon
Primary request: Create one clean icon concept named Progress Mosaic for Language Tracker. Seven large rounded-square tiles on an implied 3 by 3 grid should form one cohesive diagonal route of accumulated daily progress, using negative space to suggest upward movement without a literal arrow. It should evoke a heatmap and steady learning history, not a calendar screenshot.
Scene/backdrop: full-bleed opaque deep primary-blue rounded-square app icon field
Style/medium: flat vector-friendly geometric logo exploration, crisp hard edges, minimal forms
Composition/framing: centered, generous safe margin, semantic mark entirely inside the central 60 percent
Color palette: #155DFC background, #F8FAFC, #F7C95E, #78B76D, #15803D tiles
Constraints: one standalone square icon, strong silhouette at 32 px, no letters, no words, no UI, no mockup, no border, no transparency
Avoid: book, globe, flag, speech bubble, translator symbol, tiny grid, thin lines, 3D, gradients, textures, shadows, watermark
```

Initial assessment: the heatmap connection is immediate and product-specific.
The generated arrangement is clear but still reads as separate tiles rather
than one ownable emblem. A next variant should strengthen the diagonal
negative-space route and remove the soft generated shading.

## 2. Dialogue Dial

## 3. Level Trail

File: `concept-03-level-trail-v1.png`

```text
Use case: logo-brand
Asset type: early concept render for a mobile PWA app icon
Primary request: Create one clean icon concept named Level Trail for Language Tracker. A single heavy continuous folded ribbon rises through three broad terraces, preserving the route already travelled and ending in a substantial open portal. The silhouette should feel like a compact path through learning levels, not a growth chart or trophy.
Scene/backdrop: full-bleed opaque primary-blue rounded-square app icon field
Style/medium: flat vector-friendly geometric logo exploration, crisp hard edges, minimal forms
Composition/framing: centered compact diagonal ribbon or shield-like silhouette, generous safe margin, mark inside central 60 percent
Color palette: #155DFC background, #F8FAFC trail, #10B981 endpoint; optional single #F7C95E hinge only if structurally useful
```

Initial assessment: the continuous history/path metaphor is visible, and the
open endpoint adds aspiration without a trophy. The current path is too organic
and road-like; production exploration should use a more geometric folded ribbon
with fewer turns.

## 4. Tracked L

File: `concept-04-tracked-l-v1.png`

```text
Use case: logo-brand
Asset type: early concept render for a mobile PWA app icon
Primary request: Create one clean icon concept named Tracked L for Language Tracker. Construct an abstract lowercase l from a thick vertical rounded measure and a broad incomplete circular tracking orbit crossing behind it. Add one large rounded-square marker on the orbit to echo a heatmap cell. The letter should emerge from negative space rather than look typeset.
Scene/backdrop: full-bleed opaque off-white rounded-square app icon field
Style/medium: flat vector-friendly geometric logo exploration, crisp hard edges, minimal brand mark
Composition/framing: centered balanced hook-and-ring silhouette, generous safe margin, mark inside central 60 percent
Color palette: #F8FAFC background, #0F172A main measure, #155DFC orbit segment, #10B981 square marker
Constraints: one standalone square icon, recognizable at 32 px and in monochrome, no additional letters, no words, no UI, no mockup, no border, no transparency
Avoid: location pin, power button, magnifying glass, clock hands, literal typography, globe, flag, book, thin lines, 3D, gradients, textures, shadows, watermark
```

Initial assessment: the marker and `l` are clear, but the incomplete ring reads
too strongly as a power symbol. This direction needs a substantial structural
revision—an offset orbit or less vertical stem—if selected.
