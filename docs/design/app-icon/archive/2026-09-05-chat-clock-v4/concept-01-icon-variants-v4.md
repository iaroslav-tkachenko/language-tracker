## Variant A — Chat Lines

File: `concept-01-chat-lines-clock-v4a.png`

Prompt variation: use one bold rounded dialogue window with a short restrained

make it readable without relying on the tail, but the form risks resembling a
generic messaging product.

Prompt variation: use one continuous off-white conversation ribbon folded into
