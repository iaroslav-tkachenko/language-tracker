# README screenshots

Store production screenshots used by the root `README.md` in this directory.

- Use descriptive kebab-case names such as `study-time-dashboard.png` and
  `statistics-mobile.png`.
- Prefer optimized PNG or WebP files at a readable desktop or mobile resolution.
- Check the entire image for personal email addresses, authentication links,
  browser bookmarks, notifications, and other private information before
  uploading it.
- Add concise, descriptive alt text when embedding each image in Markdown.

The root README currently uses:

- `study-time-dashboard.png`
- `statistics-dashboard.png`
- `progress-forecast-example.png`
- `vocabulary-mobile.png`
