# Twemoji Country Flags

`TwemojiCountryFlags.woff2` is the unmodified font distributed with
[country-flag-emoji-polyfill 0.1.10](https://github.com/talkjs/country-flag-emoji-polyfill).
That project created it by subsetting Mozilla's Twemoji font to flag characters.
The emoji artwork is by [Twemoji](https://github.com/twitter/twemoji), licensed
under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The upstream
license notice is included alongside this file.
